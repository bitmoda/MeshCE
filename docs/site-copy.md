MeshCE

Halo: Combat Evolved for Mac, Windows, and Linux. The original campaign and multiplayer, from the maps on your own copy of the Xbox game. Each system runs the game's own code.

The original game

The campaign, the thirteen multiplayer maps, and the Xbox look. Field of view and smooth motion are optional. The simulation stays at 30 ticks a second, as it did on the Xbox.

Your maps

The program download has no game data. You bring the original Xbox maps from your own copy. On Mac, Windows, and Linux, the first launch can read a disc image and extract the maps, or use a folder of maps you have already extracted. MeshCE plays those maps and no others.

Playing together

Mac, Windows, and Linux play together. On a local network, a game needs no invite. Up to 128 players can join, and up to four can share one screen. Campaign co-op works online. Voice chat is optional.

Custom games are hosted on one player's computer. The host shares an invite link, and the others connect to that host.

Find Game fills Free for all, 2v2, and Ranked from other MeshCE players. A new install reaches the built-in introducer and the players that machine has heard, and a local network finds players by broadcast. Matchmaking runs on the players' own computers. The player with the best connection hosts. Rank and games played change for a Find Game match. A custom game leaves them as they were.

On your computer

Windows and Linux draw with OpenGL. Mac draws with Metal. Sound, input, and gamepads go through SDL3.

On Mac, build 77 checks for a newer release and asks before installing it. A Mac on build 76 offers build 77. On Windows and Linux, a newer download replaces the program and leaves maps, saves, and settings in place.

OpenCE for Mac

OpenCE on Apple Silicon is a separate release. It keeps the OpenCE menus and gameplay. Its network protocol is 44. MeshCE does not install it, and it does not install MeshCE.

https://github.com/bitmoda/MeshCE/releases/download/opence-build-1/opence-macos-arm64.dmg

Open the disk image and drag OpenCE into Applications. Apple Silicon, macOS 26 or later. Saves go in ~/Library/Application Support/OpenCE.
